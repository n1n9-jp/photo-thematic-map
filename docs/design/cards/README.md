# 文字の載る UI の作り直し（変更の前と後）

`before/` は作り直す前、`after/` は後。同じ位置・同じ大きさで撮影している。

| ファイル | 内容 |
| --- | --- |
| `sceneN-WxH.jpg` | 場面 N の最初のカードが止まっている間の画面（1倍） |
| `cardN-WxH@2x.png` | そのカードの拡大（2倍） |
| `attribution-WxH@2x.png` | 画面の下端の出典表示（2倍） |
| `scene8-WxH.jpg`・`button*-WxH@2x.png` | 場面8の「地図を動かす」ボタン（通常・hover・focus-visible・押した後） |
| `button-states-390x844@2x.png` | ボタンの4つの状態を並べたもの |
| `methods-{top,item,end}-WxH.png` | 「データと方法」の節の冒頭・項目・末尾（2倍） |

撮影の環境はヘッドレス Chromium（SwiftShader）。端末のゴシック体は IPA Pゴシックしかない（太さは1つ）ため、和文の太字は合成で、実際の端末（ヒラギノ・游ゴシック・Noto Sans CJK）より粗く見える。数字と欧文は同梱の Inter。
地面や建物の読み込みが撮影までに終わっていない場面がある（背景の細かさは前後で揃っていない）。

## 設計の要点

- 値はすべて `src/styles/tokens.css` の `--ptm-*`（色・書体・文字サイズ・太さ・行間・余白・角丸・罫線・影・フォーカスの輪）。
- 色は 墨（ink 1〜4）・紙（paper 1〜3、面 surface）・アクセント（赤 1 色と濃淡）。最も薄い文字色 ink-3 で紙の上 5.5:1、面が黒い背景に透けても 4.8:1。
- 本文カード: 上辺の赤い太線をやめ、細い輪郭線と2層の影の面に。場面の番号「02 / 08」の横に、場面の数だけの目盛り（通り過ぎた場面・現在＝アクセント・まだ）を置く。見出しはゴシック体の太字。数値は墨の太字の等幅数字で、最終値の幅をあらかじめ確保して右に揃えるので、数え上げで桁が変わっても幅と単位の位置が動かない。
- ボタン: 墨の丸いボタン。hover は少し明るく、active は黒く 1px 沈む、押した状態（自由操作中）はアクセント、focus-visible は紙の色とアクセントの二重の輪。高さ 44px。「作品の先頭へ戻る」も同じ形。
- 出典表示・読み込みの表示: カードと同じ紙の面。リンクは墨の文字に細い下線（hover で濃く）、見えない範囲で押せる高さを 44px に広げる。
- 凡例は紙の面、駅のラベルは墨の面（地図の上の小さな札）。
- 「データと方法」: 明朝体をやめてゴシック体の太さで階層を付ける。目次は 44px の行に下向きの矢印。リンクは青から墨＋下線へ。
