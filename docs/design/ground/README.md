# 地面: 航空写真から、標高の起伏を付けた単色の地面へ

地面に航空写真（PLATEAU-Ortho・国土地理院の写真）を貼るのをやめ、国土地理院の標高タイルで起伏を付けた単色の面にした（`src/scene/plateau/ground.ts`）。

画面は `tests/e2e/ground.spec.ts` が `screenshots/ground/` に書き出したものを JPEG にした（SwiftShader の描画）。

- `after-pc-1.jpg`〜`after-pc-8.jpg`: 変更後、PC 幅 1280×720 の8場面
- `after-mobile-1.jpg`〜`after-mobile-8.jpg`: 変更後、スマートフォン幅 390×844 の8場面
- `before-*.jpg`: 変更前（航空写真）の比較用。場面1・3・5・6（PC 幅）と場面1・5（スマートフォン幅）
- `before-elevation-*.json`・`after-elevation-*.json`: 場面ごと（前の場面から移る間を含む）の標高タイルの件数と転送量

## 標高タイルの転送量（場面ごと、MB）

`tests/e2e/ground.spec.ts` で測った値（ブラウザのキャッシュから返った要求は 0MB）。変更後は、航空写真のころにあった
「浅い角度で見るタイル・霧の掛かるタイルは粗く」「カメラが動いている間は新しく読むタイルを粗く」を標高の四分木に戻した後の値。
戻す前は PC 10.0MB・スマートフォン 4.0MB（場面1 3.5MB、場面5 2.2MB など）だった。

変更後は約 2 割多い。航空写真のころは、写真のない範囲（海・23区の外）の地面のタイルを作らなかったので、その範囲の標高も読まなかった。
いまは標高タイルの範囲（陸）すべてに地面を作る。航空写真のタイル（変更前は PC で 194件）は読まない。

## 細かさの上限

最大ズームを 19 から 18 に下げた（標高は 5m メッシュまで）。同じ8場面の画面を比べ、15 階調を超えて違う画素は 0〜0.04%（山の裾の数画素）で、見た目は変わらない。

## 色

| 部分 | 色 | 理由 |
| --- | --- | --- |
| 陸 | `#77746d`（`BASE_LAND_COLOR`） | 明るさが中ほどの、わずかに温かい灰色。白い建物（`#e9e7e2`、陰の面でも `#a0a0a0` 前後）より十分に暗く、建物の輪郭と足元が分かる。彩度が低いので、駅の柱の黄〜紫と赤いアクセント（`--ptm-accent`）の色を濁さない。黒い自転車とは明るさで、銀の自転車とは色味で分かれる。もとは航空写真の遠景の平均に近い色として選んだもので、写真をやめても場面の明るさの印象が大きく変わらない。 |
| 海 | `#5f7f96`（`BASE_SEA_COLOR`） | 陸より暗く、空（`#bfd9ee`）より濃い青灰色。俯瞰で海岸線がはっきり分かれ、霧で遠くが空の色に溶けても陸と海の順に明るさがそろう。 |
| 陰影 | 陸の色の ±16%（`RELIEF_STRENGTH`）、傾きを 1.5 倍に強調（`RELIEF_EXAGGERATION`） | 光はシーンの太陽と同じ西南西の上から。山の手の台地の縁や多摩の丘陵が俯瞰で読み取れ、地上の目線では平らな面とほぼ同じに見える強さ。 |

## 画面で確かめたこと

- 地面の抜け（空の色が見える穴）はない。23区の外も、起伏の付いた地面と同じ色の平らな地面が続く。
- 自転車・自転車の山・建物の足元は地面に接していて、浮きや埋まりは見当たらない。
- 東京湾の海岸線は、標高の無効値の境で切れ、下の海の色が見える。

## 標高タイルの縁

5m メッシュのタイルの縁の外の画素は 10m メッシュから引くことがあり、そのまま差を取ると縁に沿って陰影の線が出る。
傾きは同じ標高タイルの画素どうしで求める（`buildSurface`）ので、変更後の画面に線は出ていない。

## 気になる点

- 場面3（俯瞰）の左上に、起伏の付いた地面を敷く範囲（`GROUND_ROOT_BOUNDS`、西端 東経139.22°）の直線の縁が薄く見える。その外は同じ色の平らな地面で、陰影だけがなくなる。

- 場面5（行幸通り）の手前と、場面2・8（秋葉原）の線路沿いに、細長い暗い陰影が出る。5m メッシュの標高そのもの（地下への傾斜路・線路の切り通しなど）の起伏で、陰影を控えめにしたので目立たない程度にした。
- 場面1の画面の上端に、建物の間から空の色がのぞく。変更前も同じで、地面とは関係しない。
