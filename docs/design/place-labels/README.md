# 街の上の地名

本編の街の上に、代表的な地名を文字で出す。航空写真の地面をなくして単色の地面にすると、写真に写っていた川・お堀・道路が見えなくなるので、地名が「どこを見ているか」の主な手がかりになる。

- データ: `src/story/content/placeNames.ts`（地名の一覧 `PLACE_NAMES` と、場面ごとに出す地名 `SCENE_PLACE_NAMES`）
- 表示: `src/scene/placeLabels.ts`（選び方・配置の純粋関数と、DOM の重ね表示 `PlaceLabels`）
- 本編への組み込み: `src/app/placeLabelsLayer.ts`（`createApp.ts` が毎フレーム呼ぶ）
- 主役を避ける形: 場面のモジュールの `labelKeepOut()`（`src/app/sceneModule.ts`）
- 確認ページ: `demos/place-labels.html?scene=<場面 id>`、E2E: `tests/e2e/place-labels.spec.ts`、単体テスト: `tests/unit/placeLabels.test.ts`

## 表示の規則

1. **出す地名**: いまいる場面の一覧（先頭ほど優先）。場面の間をカメラが移っている間（場面内の進捗がカメラの止まっている区間を過ぎてから次の場面に入るまで）は何も出さない。ただし次の場面も同じ一覧なら（場面3→4 の俯瞰）出し続ける。自由操作の間は、その場面の一覧を出し続ける。
2. **段階**: カメラの高さ（真下の地表から）で出す段階を変える（`PLACE_TIER_HEIGHTS`）。
   - `region`（湾・大きな川・皇居・空港）: 2,500m 以上
   - `district`（地区・駅・大きな建物）: 20m 以上 8,000m 未満
   - `local`（通り・橋・線路・駅の出口）: 2,000m 未満
3. **範囲**: 注視点からの水平距離が、カメラから注視点までの距離の 4 倍（150m より狭くしない）を超える地名は出さない。寄ったときに遠くの地名が地平線に並ぶのを防ぐ。
4. **置ける場所**: 本文カードに覆われていない範囲（駅のラベルと同じ `readOverlayLayout`。PC 幅はカードの列の右、スマートフォン幅は上側）。地点がその範囲の外なら出さない。
5. **重ねないもの**: 地名どうし・本文カード・表紙・出典表示・自由操作のボタン・読み込みの表示・駅のラベルと凡例（DOM の矩形）、駅・建物の地名の印、場面の主役（自転車 462台の位置〔まだ現れていない分も含む〕、山を囲む円錐〔裾の直径の 1.05 倍、積もる前から〕、駅の柱の底から頂点まで）。地名どうしは 12px 以上離す（隣り合う2つの地名がひと続きに読めないように）。置けない地名は出さない。PC 幅は 8 つ、スマートフォン幅は 5 つまで。
6. **置き方**: 広がりの名前（地区・川・道路）は地点を中心に置き、重なるときは文字の高さの 1.6 倍・幅の 3 割まで上下左右にずらす。駅・建物の名前は地点に小さな丸の印を付け、文字を印の右・左・上・下に置く。そこが埋まっていれば、地点の真上へ 24px・44px 離して置き、印から引き出し線を引く（山の後ろの駅舎など）。印そのものが主役や本文カードに掛かる地点は使わない。川・駅舎・公園など、地点の周りが埋まりやすい地名は、別の候補の地点（`alternatives`、川なら水面の別の点）も順に試す。前回出していた地名と、その置き場所を先に試し、カメラが少し動いたくらいでは位置を変えない。
7. **出入り**: 不透明度の切り替え（320ms、`--ptm-place-fade`）。消える地名も消えきるまで地点に付いて動く。動きを減らす設定では切り替えを省く。

## 見た目

駅のラベル（台数を示すデータ）は墨の札に白い文字。地名（案内）は札を付けず、墨の文字に紙の色の縁取り（`--ptm-place-halo-shadow`）を付けて区別する。縁取りがあるので、明るい地面・暗い地面・白い建物のどの上でも読める。

| 種類 | 例 | 文字 |
| --- | --- | --- |
| 俯瞰の目印（region） | 東京湾・荒川・羽田空港 | 16px（狭い画面 15px）、中くらいの太さ |
| 地区・駅・建物（district） | 秋葉原駅・八重洲・新宿中央公園 | 15px（狭い画面 13px） |
| 近くの名前（local） | 総武線・行幸通り・電気街口 | 13px（狭い画面 12px） |
| 川・湾（water） | 東京湾・神田川 | 淡い墨（`--ptm-ink-2`）、字間 0.3em |
| 道路・線路（road） | 行幸通り・総武線 | 淡い墨、細め |
| 駅・建物（point） | 秋葉原駅・東京都庁 | 太字、地点に墨の丸い印 |

強制カラーでは縁取り（影）が消えるので、システムの背景色の面に載せる。

## スクリーンリーダー

地名の重ね表示は `aria-hidden="true"`（装飾）にした。地名は本文（場面の見出しと本文）が言葉で伝えている場所（秋葉原駅前、東京駅丸の内口、新宿の都庁前・新宿中央公園）の補助で、カメラが動くたびに出入りし、並びも変わる。読み上げの対象にすると、場面が進むたびに地名の断片が読まれ、本文の流れを妨げる。

## 画像で分かっていること

- 23区の俯瞰（場面3・4）では、都心の柱が密集しているので、皇居と隅田川は置けない（柱を隠さない規則を優先した）。荒川は場面3 の PC 幅だけ。
- 寄った場面では、地点が本文カードの下や画面の外に来る地名（PC 幅の場面2・8 の中央通り・昭和通り・神田川・万世橋・町名、場面5・7 の大手町・丸の内・有楽町・皇居外苑、場面6 の新宿駅・山手通り）は出ない。一覧には残してあり、画面の形が違う端末（タブレットなど）や、場面8 の自由操作で動かしたときに出る。
- 東京駅の丸の内駅舎は、中央玄関の屋根が山の頂上の真後ろに来るので、北寄りの屋根に置かれる（幅 320 では真上へ離して引き出し線を引く）。
- 地上の目線の場面1は「電気街口 駅前広場」だけ。
- 確認ページの画像は、航空写真が読み込まれる前の暗い単色の地面の上でも、縁取りで地名が読めることを示す（単色の地面の担当の変更後の見え方に近い）。
