# 東京都の駅前放置自転車データ

作品に出る数字の根拠になるデータです。`npm run data:bicycles`（`scripts/data/build-bicycles.ts`）が `data/raw/bicycles/` の原本から生成します。手で編集しないでください。原本の取得元・取得日・利用条件は [`data/raw/bicycles/SOURCES.md`](../../../data/raw/bicycles/SOURCES.md) にあります。

スクリプトは生成のたびに、下の「公表値との照合」に挙げた値を一次資料の記載と突き合わせ（約3,000件）、一つでも合わなければ失敗します。

## 調査の定義（全文 凡例 p.-〔PDF物理ページ5-6〕より）

| 用語 | 定義 |
| --- | --- |
| 駅周辺 | 原則として鉄軌道駅から概ね半径500m以内の区域 |
| 放置 | 自転車等が自転車等駐車場以外の道路に置かれ、利用者が直ちに移動できない状態 |
| 放置台数 | 駅周辺の自転車・原動機付自転車・自動二輪車の放置台数。**2025年10月中の晴天の平日のうち任意の1日、概ね午前11時頃**の1回の数え上げ |
| 実収容台数 | 調査時に自転車等駐車場に実際に駐車している台数 |
| 収容能力 | 自転車等駐車場の整備計画上の収容予定台数（2025年8月末現在）。定めがなければ自転車1台幅40cm、原付・自二1台幅60cmで換算 |
| 乗入台数 | 放置台数＋実収容台数 |
| 自転車等 | 自転車及び原動機付自転車（自動二輪車を含まない）。**撤去・返還・処分の台数はこの「自転車等」** |
| 一般原付／特定原付 | 原付のうち道路交通法 2条1項10号イ／ロ（特定原付＝電動キックボード等の特定小型原動機付自転車） |
| 対象区域 | 島しょ地区を除く都内区市町村 |

## ファイル

### `municipalities.json` 区市町村別

島しょを除く **53区市町村**（撤去表の並び）。

- `parked` / `occupancy` / `capacity` / `inflow`: 駅別 Excel の区市町村「計」行（2025年10月）。駅のない檜原村は `null`。
- `bicycleParkedRatePercent`: 自転車の放置率＝自転車放置台数 ÷ 自転車の乗入台数（概要 p.1 と同じ定義。全文 p.7 の「放置率」は分母が自転車・原付・自二を合わせた乗入台数なので値が少し違う。例: 千代田区 概要46.5％／全文44.4％）。
- `removalFY2024`: **令和6年度（2024年4月〜2025年3月）に区市町村が撤去・返還・処分した台数**（全文 p.51 (3)）。`total`＝計、`bicycle`＝自転車、`moped`＝原付。`returnRatePercent` は原本の「（参考）返還率」。
  - **撤去台数は区市町村単位でのみ公表**されています。駅単位の撤去台数はありません（駅単位で取れるのは調査日1日の放置台数だけ）。
  - 返還・処分台数には前年度に撤去されたものを含み、処分台数には粗大ごみとして収集されたもの等を含む場合があるため、撤去＝返還＋処分にはなりません（凡例 2(3)）。
  - あきる野市・日の出町は処分費用を折半しているため、処分台数に小数（122.0 など）が出ることがあります（p.51 注）。
  - 江戸川区は原本で処分台数の「計」4,936 が「自転車 4,540＋原付 2」より 394 台多く、そのため総数行も 394 台ずれています（原本どおり収録し `notes` に記録）。

### `timeseries.json` 都全体の推移

- `parking.series`: 1999年（平成11年）〜2025年（令和7年）の各年の調査日1日の乗入台数・実収容台数・放置台数（全文 p.26-27「都」の行）。`mopedMotorcycle` は表の下段（ ）内の原付・自二の内数、`parked.bicycle` は「計−内数」でスクリプトが算出した自転車のみの放置台数。
  - `countingMethod: "threshold"`（2011年まで）は、駅ごとに自転車100台以上、原付・自二は合わせて50台以上の場合だけ放置台数を計上した旧方式。`"all"`（2012年から）は1台から計上。**2011→2012年の増加（42,311→52,712）は数え方の変更によるもの**で、実際に増えたわけではありません。
  - p.26-27 の表は過去の値も最新の数え直しで載せています。各年度の報告書に当時載った値とは、平成24年だけ違います（当時の報告書 52,796台・自転車48,197台、最新の表 52,712台・自転車48,113台）。それ以外の年の自転車放置台数は、各年度の全文の駅別表の総数行と一致しました。
- `removal.series`: 2010〜2024年度の撤去・返還・処分の台数（自転車＋原付）。各年度の全文の「区市町村の撤去・返還・処分状況」総数行。年度ごとに `source`（URL とページ）を持ちます。2015年度（平成28年度調査）は原本 PDF が画像のみなので目視で転記（計＝自転車＋原付が3項目とも成立、処分の計は同 PDF の円グラフの合計とも一致）。2017年度は原本で撤去の計 359,826 が自転車＋原付より95台多い（`notes`）。

### `summary.json` 主要な数値

各数値に `value`・`unit`・`period`（調査日または年度）・`definition`・`sources`（資料名・URL・ページ）を持たせています。

## 位置合わせ（Excel の駅名 → 国土数値情報 N02）

1. Excel の駅名を「、」で分け、「駅」を除く。ラベル全体が N02 の1駅名なら分けない（「大塚・帝京大学」「中央大学・明星大学」）。それ以外の「・」も分ける（「金町駅・京成金町駅」）。
2. 表記を揃える: Unicode NFKC 正規化（N02 は「笹塚」の「塚」に互換漢字 U+FA10 を使っている）と、ヶ→ケ。
3. 表記揺れ・路線の指定（スクリプトの `ALIASES`）: 二重橋→二重橋前、霞が関→霞ヶ関、都電早稲田・都電面影橋→都電荒川線の停留場、つくばエクスプレス浅草→首都圏新都市鉄道の浅草、京成江戸川→京成本線の江戸川、永山→京王永山＋小田急永山、浅草（台東区の行）→TX を除く東武・メトロ・都営、早稲田（新宿区の行）→東京メトロ東西線。
4. N02 の駅（路線ごとのホームの線分）の中点を求め、同名で 1.5km 以内のものは同じ駅とみなして平均（複数路線の駅は全路線の平均）。東京都とその周辺の範囲外（例: 埼玉県の霞ヶ関駅）は候補から除く。
5. 同名の駅が離れて2か所以上ある場合は、その区市町村の他の駅の位置の中央値に最も近いものを採用（該当: 港区の赤坂→東京メトロ千代田線〔富士急行の赤坂を除外〕、練馬区の平和台→東京メトロ有楽町線〔流鉄の平和台を除外〕）。
6. 複数駅をまとめた行は、各駅の位置の平均。まとめた駅どうしの最大距離を `geo.spreadM` に記録（最大469m）。
7. 検算: すべての駅が所属区市町村の基準点から15km以内、緯度経度が島しょを除く都の範囲に収まることを確かめる。

**結果: 駅名 689件すべて照合でき、663行すべてに緯度経度が付いた（未照合 0件）。**
